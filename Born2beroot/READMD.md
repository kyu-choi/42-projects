# Born2beroot

Linux 가상 머신을 직접 구성하고 보안 정책을 설정하는 시스템 관리 프로젝트입니다.

Debian 또는 Rocky 환경에서 사용자, 권한, SSH, UFW, sudo 정책 등을 설정했습니다.

---

## Tech Stack

| Category       | Stack                        |
| -------------- | ---------------------------- |
| OS             | Debian / Rocky Linux         |
| Virtualization | VirtualBox / UTM             |
| Security       | SSH, UFW, sudo policy        |
| System Admin   | User, Group, Password Policy |

---

## Main Features

* 가상 머신 설치
* 사용자 및 그룹 관리
* sudo 권한 설정
* SSH 서버 설정
* UFW 방화벽 설정
* 비밀번호 정책 설정
* monitoring script 작성
* cron 기반 주기 실행

## Portfolio Point

이 프로젝트는 개발 환경의 기반이 되는 Linux 시스템 운영 경험을 보여줍니다.
임베디드/서버/로봇 개발 모두 Linux 환경 이해가 중요하기 때문에, 시스템 기초 역량으로 연결됩니다.
